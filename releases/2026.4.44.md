![Rilvune editor](https://raw.githubusercontent.com/troomen/Rilvune/v2026.4.44/docs/editor.png)

### Highlights

- **Java included.** The editor and its Java runtime travel together in one Linux executable.
- **Portable launch.** No Java installation or Docker required to run the release.
- **Verified downloads.** A SHA-256 checksum accompanies the executable; its embedded payload is also checked on every launch.

### Get started

Download the executable, then run:

```bash
chmod +x rilvune-2026.4.44-linux-x86_64
./rilvune-2026.4.44-linux-x86_64
```

To verify your download, save the checksum beside the executable and run:

```bash
sha256sum --check rilvune-2026.4.44-linux-x86_64.sha256
```

### Requirements

Linux x86_64 with an X11/XWayland desktop; Ubuntu 24.04 or a compatible newer system.
Standard desktop libraries, Bash, tar/gzip, and coreutils are required. The launcher
extracts into a private temporary directory and removes it when the editor exits.

Git features require Git. The agent panel downloads its pinned OpenCode runtime
during setup and requires network access and provider authentication.

### For developers

`make release` builds and tests the executable, replacing previous local release
output. `make publish` uploads all staged platform artifacts and checksums to a
tagged GitHub release with these notes.
