Rilvune — one release for Linux and macOS

Linux: run ./rilvune from this directory.
macOS (Apple Silicon or Intel): move Rilvune.app into Applications and open it.
CLI: Rilvune.app/Contents/MacOS/Rilvune --help

The complete application and Java runtimes are included. Keep the app bundle
intact. No installed Java or Docker is needed on supported platforms.
Linux requires a glibc desktop with X11/XWayland and standard Java desktop
libraries. Git features use the host's git executable.

OpenCode is installed on demand from the assistant panel. Sign-in and Internet
access are required for the assistant. Other editor features work independently.
Profiles are stored in your user data directory, outside this installation.
Use --profile <directory> to select another profile.

This macOS application is not Developer ID signed or notarized. Use macOS's
approval flow for applications you trust.
